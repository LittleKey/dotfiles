# 使用示例

## 1. 飞书 PRD：单节补异常流程

> 帮我在飞书 PRD 的「登录流程」一节补上验证码输错的异常流程，模板样式和里面的截图、表格都别动。

适用重点：局部新增；模板/样式/资源保真；写后回读。
配套 Skill：`lark-doc`

## 2. 飞书技术方案：落实评审意见

> 这版技术方案按评审意见改一下：接口超时改成 5 秒，验收里那条响应时间跟着对齐；缓存那两个还没定的方案保持待定，别替我拍板。

适用重点：参数与验收口径联动；待定方案的状态保护。
配套 Skill：`lark-doc`

## 3. 本地架构文档：只润色一节

> 把 architecture.md 里「部署架构」那节润色一下，别的部分一个字都别改，改完给我看下 diff。

适用重点：范围限定；最小变更；用 diff 证明节外未动。

## 4. ADR：更新已批准的决策

> 团队已经拍板用 PostgreSQL 了，把 ADR-007 里那条待定的存储选型更新成已定，后果和影响一起补上。

适用重点：经确认的决策状态更新与后果同步；决策/术语治理。
配套 Skill：`domain-modeling`（若 ADR 托管在飞书，另加 `lark-doc`）

## 5. 显式全文重构

> 这篇文档结构太乱了，按我给你的新大纲整体重排一遍；里面的数据、术语、链接和嵌入的表格图片都不能丢，先读目录再动笔，写完回读核对一遍。

适用重点：全文重构需明确请求；事实/资源保护；大纲定位与写后验证。
