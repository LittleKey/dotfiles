# 平台适配

本 Skill 只做能力判断与选择，不复制平台命令语法。飞书操作按名称复用既有平台 Skills，不维护第二套命令，也不作无损编辑承诺。

## 能力门径

- 飞书 Docx/Wiki 正文操作：调用 `lark-doc`；其体裁（genre）references 按需加载，不预载。
- 飞书原生 Markdown：调用 `lark-markdown`。
- ADR 与术语治理：在本 Skill 之外追加调用 `domain-modeling`。
- 本地 Markdown：使用宿主环境常规文件读/写工具，写后比对受影响 diff。
- 其他平台：先核实实际能力再动手——读、写、版本/快照、结构（块/大纲）、资源、视觉核验，逐项确认。

## 保真边界

- 纯文本/Markdown 读取不能反映完整样式或嵌入资源状态；据此只能下文本层结论。
- XML/富文本/块级支持不等于无损编辑。
- 需要保护的对象：图片、附件、画板、嵌入表格、引用、锚点、评论关联。没有平台能力证据或视觉证据时，不得声称已保全。
- 资源无法保全时，先缩小操作范围（只动可保全的块）；缩小后仍不安全则停止，并说明能力限制。
- 声明必须与证据匹配：实际用了什么读取/核验能力，就只能下什么结论；计划中的核验不等于已完成的核验。
