# 文档类型检查维度

下表是按需检查维度，不强制作为章节标题，也不要求逐条补齐。既有模板和用户明确要求优先；某维度缺失不自动等于缺陷，仅在写新内容、补写或评审时作为检查视角使用。

| 文档类型 | 按需检查维度 |
|---|---|
| PRD | 业务目标、用户场景、规则、异常、边界、验收 |
| 技术方案 | 约束、备选方案、取舍、设计、风险、上线、回滚 |
| 架构方案 | 边界、职责、交互、部署、质量属性、演进 |
| 技术设计与接口 | 契约、字段、错误、兼容性、幂等、安全、示例 |
| 项目文档 | 范围、里程碑、依赖、责任、风险、交付条件 |
| 决策记录 | 背景、状态、选项、理由、后果 |

不提供统一模板，不强制新增目录。涉及状态表述（尤其决策记录）时，遵循 `content-boundaries.md` 的事实与决策状态区分。
