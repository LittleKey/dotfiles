# 编辑工作流

按风险伸缩的编辑流程。小改可压缩步骤；高风险环节（非幂等重试、资源保真、联动一致性）不可跳过。

## 1. 理解任务与变更层级

确认文档类型、读者、目标、范围和受保护内容；上下文充分时不重复询问。

五个变更层级，默认取满足目标的最小层级：

1. **文字替换**：同义改写、数值/参数修改。
2. **局部新增**：在既有结构内补句子、条目、单元格。
3. **段落润色**：不改信息量的表达优化。
4. **章节重构**：调整章节内结构与顺序。
5. **全文重构**：目录级调整，需明确请求或说明理由。

## 2. 读取现状

- 小任务：读取目标及必要邻近上下文。
- 大文档：先读目录/大纲，再定位相关章节。
- 同名标题或重复文本：用章节路径加邻近文本或块标识唯一定位；绝不裸用全局标题替换。
- 按风险加读：结构、样式、资源和关联内容。

## 3. 内部修改计划

内部形成：目标锚点、候选修改、联动位置、验证方式。写入前先检查依赖：目录、交叉引用、术语、API、指标、验收标准、决策状态。

相关参数或验收值出现多处时，必须同步修改或作为阻塞冲突抛出；不得假设两处出现互不相干——“相关”即需核实关系，核实后要么联动更新，要么把冲突交用户决策。

## 4. 候选正文与预检

先读取/解析来源，再生成候选：来源文本、目标定位或必要事实未就绪时，不生成候选正文——按 `content-boundaries.md` 的存在条件把“未生成”状态留在聊天通道，先读取或澄清。候选只含可原样写入的逐字最终内容；删除目标、块标识、重试逻辑、来源保留说明、最终状态断言等操作元数据一律放入写入计划，不进候选。三通道是逻辑分类而非配额：定位、删除等操作参数由写入计划提供，不属于正文内容，纯删除编辑可以没有候选正文文本——不为凑齐三类产物给纯删除伪造正文候选，也不因没有正文候选而拒绝合法删除。

生成后按 `content-boundaries.md` 的输出契约与预检清单检查：过程污染、事实状态、修改范围、结构与资源风险。此处不重复其细则。

## 5. 最小可行写入

- 使用平台支持的最小可行操作；有依赖的内容按顺序写入。
- 保留：标题层级与编号、段落/列表样式、表格列与列序及单元格格式、强调、链接、代码块、引用、术语、语言、信息密度。
- 不为美化把散文改成列表，不擅自添加图示或标注块。
- 不因笼统保真顾虑拒绝：前置阻塞已解决且操作范围明确时，检查受影响块，用平台支持的最小安全操作完成请求。仍可阻塞、提问或停止的情形：事实冲突、目标或范围歧义、不可逆高影响操作、必要来源不可用、资源无法安全保全。

## 6. 回读验证

写入后回读受影响范围，检查：落地、重复、遗漏、格式变化、资源状态、必要联动。复杂渲染（如表格、图片、画板）在视觉能力可用时必须做视觉核验；结构检查可以补充，但不能替代视觉核验。视觉能力不可用时，如实声明该限制，不声称已完成视觉核验。只报告实际执行过的检查；未执行的项目列为遗留风险。

## 7. 聊天反馈

在聊天中简述：变更范围、实际执行的动作、实际获得的证据、遗留风险与限制。明确区分计划验证与已完成验证。验证报告由当前实际执行状态驱动：本轮未执行文档读取、写入或写后验证时，以 `当前实际状态：未执行文档读取、写入或写后验证。`（或语义等价表述）开头或显著标明，计划项用未来/待执行措辞；用户索要未来/模板报告时标注 `模板（执行后填充）`，完成项为待填充字段，不呈现为当前事实。反馈只留在聊天，不写入正文。

## 失败、超时、部分成功与并发修改

非幂等写入重试前：

1. 重新读取当前状态；
2. 检测目标文本是否已部分落地，判定部分成功范围；
3. 有版本/快照能力时，比较版本或目标快照；
4. 只写入剩余差异。

定位失效时（结构编辑或并发替换后，原锚点、邻近文本或块标识不再命中或不再唯一）：

1. 立即作废旧定位，不得继续按其写入；
2. 重读当前结构与内容；
3. 用章节路径加邻近锚点与内容同一性重新唯一定位，确认找到的仍是原计划目标；
4. 只对剩余意图变更重试；
5. 同一性有歧义、无法确认目标时停止并澄清，不得猜测写入。

超时且结果未知时禁止盲目重试——重复插入与覆盖是主要后果。发现并发修改导致目标内容变化时，重新评估计划再继续。

## 何时必须提问

只在以下情况提问：

- 事实冲突：两处来源矛盾且影响产出；
- 目标或范围歧义且不同理解会改变结果；
- 不可逆的高影响操作；
- 安全写入所必需的来源不可用。

普通措辞、排版选择不问，按最小修改原则处理。
